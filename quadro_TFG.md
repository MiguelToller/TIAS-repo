# Resumo do Trabalho de Conclusão de Curso

| Tópico | Detalhes |
| :--- | :--- |
| **Título do trabalho** | Aplicativo Móvel para Controle de Vacinação para Setores Públicos e Privados |
| **Curso** | Curso de Ciências da Computação - Universidade Franciscana |
| **Nomes (aluno e orientador)** | Gabriel Toller Marconatto e Gustavo Stangherlin Cantarelli |
| **Descrição básica do trabalho** | O trabalho apresenta o desenvolvimento de um aplicativo móvel para informatizar a carteira de vacinação nos serviços público e privado. O objetivo é substituir o uso de papel, facilitando o armazenamento e o acesso rápido aos dados de imunização tanto para os profissionais da saúde quanto para os pacientes. |
| **Rotinas da Saúde trabalhadas** | **Monitoramento:** O aplicativo permite o controle e acompanhamento do histórico de vacinas aplicadas nos pacientes.<br>**Recomendação:** O sistema informa o cidadão sobre quando ele deve se vacinar, incluindo o envio de mensagens sobre datas, locais e público-alvo de campanhas de vacinação, bem como quais vacinas o paciente precisa tomar. |
