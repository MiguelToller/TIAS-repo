## 1. Faixa Temporal
* Classificação temporal utilizada em análises: **Meses, Semestres, Anos, Décadas**.

---

## 2. Contexto do Processo de Análise
1. **Predição ou Previsão:** Definição do objetivo analítico.
2. **Escolha da Base de Dados:** Seleção das fontes de dados primárias.
3. **Aplicação do ETL:** Limpeza, transformação e estruturação.
4. **Definição do Modelo (Benchmark):** Estabelecimento de um modelo de referência inicial.

---

## 3. Universo vs. Amostra
* **Estatística (Previsão):** Partir de uma **amostra** para inferir/definir o **universo**.
* **Mineração (Predição):** Partir de um **universo** de dados para selecionar uma **amostra** representativa.

---

## 4. Escolha do Melhor Modelo
* **Critério:** Depende diretamente da divisão entre os dados de **treino e testes** (ex: proporção padrão de **70% para treino e 30% para testes**).

---

## 6. Normalização de Dados
* **Objetivo:** Retirar os valores extremos (*outliers*) para garantir maior estabilidade e precisão no treinamento do modelo.
